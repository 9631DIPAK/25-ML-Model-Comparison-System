# 25-ML-Model-Comparison-System



ML Algorithms Comparison: Classification & Regression

This project implements various machine learning algorithms for both classification and regression tasks:

Regression: Uses the Housing dataset to predict house prices.

Classification: Uses the Iris dataset to classify flower species.

Performance Comparison: Evaluates each model using metrics like accuracy, precision, recall, F1-score (classification) and RMSE, MAE, R² (regression) to determine the best-performing algorithm.

Tech Stack: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
